# 4.1 Data layer — plan (auto-approved, autopilot)

- `src/lib/db.ts`: Dexie db `studysite`, v1 tables: attempts, criterion, cards (FSRS state), requeue, sessions,
  annotations, settings. Keys are stable content ids. All timestamps are epoch ms.
- `src/lib/selectors.ts`: pure functions over plain arrays (no Dexie import) so Vitest can test them directly:
  accuracyByConcept, calibration (sure/unsure/guess → accuracy), dueCards, dueRequeues, daysStudied(last 14),
  minutesToday, readiness(unit). Day boundaries use Australia/Sydney.
- `src/lib/store.ts`: Zustand store hydrated from Dexie via liveQuery; hooks wrap the selectors.
- Readiness = 0.6 × mean criterion progress (none 0, learning ⅓ of correctInSession/3 … learned 0.5, +⅙ per relearn,
  secured 1) + 0.4 × mean recent accuracy (last 10 attempts per concept), over the unit's concepts. "On track" compares
  it with a linear target rising from 0 at 42 days before the exam to 0.9 on exam day.
- Tests: tests/selectors.test.ts (accuracy, calibration, days-in-14 across a timezone edge, readiness, due ordering).
