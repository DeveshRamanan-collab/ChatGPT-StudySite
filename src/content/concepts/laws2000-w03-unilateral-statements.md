A unilateral statement is a "non-treaty" action that can still create binding obligations in international
law: "a state may evidence a clear intention to accept obligations vis-à-vis certain other states by a
public declaration which is not an offer or otherwise dependent on reciprocal undertakings from its
addressees" (Crawford, *Brownlie's Principles*). The defining difference from a treaty is reciprocity: a
unilateral statement is one state committing itself, with no counterpart state agreeing to do anything in
return, and it does not need to be in writing.

The *Eastern Greenland Case* and the *Nuclear Test Cases* (Australia v France, New Zealand v France) both
show a public declaration by a state can bind that state internationally, without any other state's
acceptance needed to make it binding — unlike a treaty, which needs at least two consenting parties.

Exam use: if only one state is committing to something, with no other state agreeing to anything in
exchange, ask whether it is a unilateral statement rather than forcing it into the treaty analysis — and
note that a reservation (a different, treaty-specific concept) is itself made "unilaterally" too, so do not
confuse the two: a reservation modifies an existing treaty relationship, a unilateral statement stands
alone.
